# CAP Food Pantry Website

Responsive multi-page website for the Christian Assistance Program (CAP) Food Pantry.

## Pages

- Home
- Get Food
- About Us
- CAP Churches
- Partners
- Donate & Volunteer
- Contact Us

## Preview locally

Open the project folder in VS Code and use **Live Server** / **Go Live**. Then visit the local URL shown by VS Code, such as `http://127.0.0.1:5500/`.

## Contact form

The contact form submits directly from the website and does not open the visitor's email application. The current form recipient is `giancarlos.reyes04@gmail.com` for testing and demonstration. Before the production launch, update the form `action` in `contact.html` to the final CAP recipient email and complete the provider's one-time recipient verification.

## Content note

The pantry's public information is based on the August 2026 CAP materials supplied for the project. Donation and volunteer needs can change, so those pages direct visitors to contact CAP for current details.
